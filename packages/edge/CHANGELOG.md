# Changelog

All notable changes to `@forge-fr/edge` will be documented in this file.

## [1.0.0] - 2026-11-27

### Added & Changed
- Synchronized `@forge-fr/edge` to `1.0.0` General Availability with zero-alias Cloudflare Workers (`workerd`) and Deno bundling.

## [0.1.0] - 2026-11-25

- Initial release of `@forge-fr/edge` supporting Cloudflare Workers, Deno Deploy, and standard WinterCG Web Fetch runtimes with cold-boot synchronization, `waitUntil` propagation, and `WeakMap`-scoped edge bindings.
