# Changelog

All notable changes to `@forge-fr/config` will be documented in this file.

## [1.0.0] - 2026-11-27

### Added & Changed
- Promoted `@forge-fr/config` (`defineConfig`, `loadConfig`, `createConfigLoader`, `parseDotEnv`, `redactConfig`, `createConfigPlugin`, `ConfigTokens`) to `1.0.0` General Availability.

## [1.0.0-rc.2] - 2026-11-27

### Added
- Initial release of `@forge-fr/config`: `defineConfig`, `loadConfig`, `createConfigLoader`, `parseDotEnv`, `redactConfig`, `ConfigValidationError`, `createConfigToken`, and `createConfigPlugin`.
- Added `@forge-fr/config/node` subpath for Node.js/Bun `.env` file loading (`loadDotEnvFiles`, `loadDotEnvFilesSync`, `loadNodeConfig`).
