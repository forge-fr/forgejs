# ForgeJS

> Build clear, well-structured TypeScript backends for Node.js, Bun, and Cloudflare Workers with built-in validation, safe defaults, and zero runtime lock-in.

ForgeJS v1.0.0 is a clear, modular, pure-ESM TypeScript backend framework built on Web Standards for Node.js (>=22.18.0), Bun (>=1.4.0), and WinterCG Edge runtimes across 21 focused `@forge-fr/*` packages.

## API Reference (21 @forge-fr/* Packages)

- [API Directory Overview](https://github.com/forge-fr/forgejs/api.md): Layer overview, package sizes, dependencies, and links to all 21 packages.
- [@forge-fr/core](https://github.com/forge-fr/forgejs/api/core.md): App startup lifecycle, typed service container, isolated feature modules, permission-checked plugins, config, events, errors, secrets, and health checks.
- [@forge-fr/config](https://github.com/forge-fr/forgejs/api/config.md): Strongly typed environment and .env configuration validated with Zod, Valibot, or Standard Schema v1, with automatic secret redaction and Edge-safe loaders.
- [@forge-fr/router](https://github.com/forge-fr/forgejs/api/router.md): Zero-dependency URL router with instant static path lookup, typed parameter patterns, wildcards, route groups, and automatic HEAD/405 responses.
- [@forge-fr/http](https://github.com/forge-fr/forgejs/api/http.md): Web-standard HTTP server with typed ContextKey<T> state, layered middleware, streaming multipart/binary body readers, SSE/WebSocket pub-sub RealtimeHub, compression, and ETags.
- [@forge-fr/node](https://github.com/forge-fr/forgejs/api/node.md): Node.js HTTP server adapter with fast direct request handling, native WebSocket upgrades, and clean shutdown on SIGINT/SIGTERM.
- [@forge-fr/bun](https://github.com/forge-fr/forgejs/api/bun.md): Bun server adapter powered by Bun.serve() with fast HTTP handling, native WebSockets, in-flight request draining, and graceful shutdown.
- [@forge-fr/edge](https://github.com/forge-fr/forgejs/api/edge.md): Edge Fetch adapter for Cloudflare Workers, Deno, and serverless isolates with zero Node or Bun globals plus background task helpers.
- [@forge-fr/testing](https://github.com/forge-fr/forgejs/api/testing.md): First-class testing harness with createTestKernel/createTestApp, typed DI overrides, in-memory HTTP/SSE/multipart/cookie-jar TestClient, and WebSocket pairs.
- [@forge-fr/validation](https://github.com/forge-fr/forgejs/api/validation.md): Input and response validation for Zod, Valibot, and any Standard Schema v1 library, with automatic OpenAPI 3.1 schema attachment, field stripping, and prototype-pollution guards.
- [@forge-fr/database](https://github.com/forge-fr/forgejs/api/database.md): PostgreSQL adapter built on postgres-js with UnitOfWork (.afterCommit/.afterRollback), defineRepository, clean error mapping, hidden connection passwords, and SQL migrations.
- [@forge-fr/drizzle](https://github.com/forge-fr/forgejs/api/drizzle.md): Official Drizzle ORM plugin with createDrizzleUnitOfWork that preserves 100% of Drizzle TypeScript inference, adds typed transactions, and maps PostgreSQL errors cleanly.
- [@forge-fr/prisma](https://github.com/forge-fr/forgejs/api/prisma.md): Official Prisma ORM adapter for Prisma v5, v6, and v7+ clients with createPrismaUnitOfWork, consistent error mapping, safe transactions, and clean shutdown.
- [@forge-fr/auth](https://github.com/forge-fr/forgejs/api/auth.md): Argon2id (Node/Bun) and Web Crypto PBKDF2-SHA256 (Edge) password hashing, typed AuthIdentityKey, strict JWT/JWKS verification, hashed sessions/API keys, OAuth 2.0 PKCE, and Better Auth.
- [@forge-fr/authorization](https://github.com/forge-fr/forgejs/api/authorization.md): Role-based (RBAC) and attribute-based (ABAC) access control, resource ownership checks, tenant isolation guards, and service-level authorizers.
- [@forge-fr/security](https://github.com/forge-fr/forgejs/api/security.md): Unified createSecurityMiddleware composer, OWASP ASVS 5.0.0 headers, CSP, strict CORS, CSRF checks, sliding-window & Redis/Postgres rate limiting, SSRF-safe fetch, and jailed paths.
- [@forge-fr/logger](https://github.com/forge-fr/forgejs/api/logger.md): Structured Pino logging (plus zero-dep @forge-fr/logger/edge) with dot-path secret redaction, typed CorrelationIdKey/RequestLoggerKey, OpenTelemetry tracing/metrics, and /health probes.
- [@forge-fr/cache](https://github.com/forge-fr/forgejs/api/cache.md): Fast LRU memory and non-blocking Redis cache adapters with stampede-safe getOrSet, tag invalidation, prefix clearing, and key validation.
- [@forge-fr/queue](https://github.com/forge-fr/forgejs/api/queue.md): Background job queues, cron/interval createJobScheduler with distributed lease locks, createTransactionalOutbox, and createDurableEventBridge for Memory, Redis, and PostgreSQL.
- [@forge-fr/storage](https://github.com/forge-fr/forgejs/api/storage.md): File storage adapters for Memory, confined local folders, and S3-compatible buckets with MIME allowlists, binary file-type checks, and signed URLs.
- [@forge-fr/openapi](https://github.com/forge-fr/forgejs/api/openapi.md): Auto-discovers OpenAPI 3.1 specs from validatedHandler() and validatedOpenApiHandler() (Zod v3/v4, Valibot, Standard Schema), with multipart/binary schemas and guarded Swagger UI.
- [@forge-fr/cli](https://github.com/forge-fr/forgejs/api/cli.md): Zero-dependency forge CLI to scaffold new apps, generate full CRUD resources/modules/schemas/repositories/services/controllers, add official plugins, and run doctor checks.
