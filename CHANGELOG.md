## [1.0.0] — 2026-11-27

### General Availability Release — Milestones 1–7 Production-Readiness Roadmap Complete (`@forge-fr/*`)
- **Milestone 1 — Public npm Distribution, Canonical `@forge-fr/*` Scope & Release Hardening:**
  - Unified all 21 workspace packages, `tsconfig.base.json`, architecture boundary checks (`63/63`), CLI starter templates, and GitHub Actions release pipelines on the canonical `@forge-fr/*` scope and `https://github.com/forge-fr/forgejs.git`.
  - Added `scripts/verify-workspace.mjs` enforcing 100% version, internal dependency range (`^1.0.0`), `FORGE_CORE_VERSION`, CLI template version, and export target consistency across all 21 packages.
  - Upgraded `scripts/verify-packaging.mjs` to verify isolated consumer `.tgz` tarball installs under both `NodeNext` and `Bundler` TypeScript resolution, Node.js 22 ESM + `require(esm)` compatibility, and Bun 1.4 smoke execution.
  - Added `.github/workflows/release.yml` to both the private and exported public (`forge-fr/forgejs`) repositories for automated topological publishing of all 21 `@forge-fr/*` packages to `https://registry.npmjs.org` with npm OIDC provenance (`--provenance --access public`).
- **Milestone 2 — Typed Core Primitives: Context State, `@forge-fr/config`, Logger Hardening & Testing Harness:**
  - **Typed Context State (`@forge-fr/http`, `@forge-fr/auth`, `@forge-fr/logger`):** Added symbol-backed `createContextKey<T>(label, options?)` and `ContextKey<T>` with lazy-allocated `ctx.set()`, `ctx.get()`, `ctx.has()`, and `ctx.require()` on `ForgeContext`, `WebSocketConnection`, and `WebSocketUpgradeContext`, plus official `AuthIdentityKey`, `CorrelationIdKey`, and `RequestLoggerKey`.
  - **Typed Configuration Package (`@forge-fr/config`, package #21 of 21):** Created `@forge-fr/config` (`defineConfig`, `loadConfig`, `createConfigLoader`, `parseDotEnv`, `redactConfig`, `ConfigValidationError`, `createConfigPlugin`, `createConfigToken`, `ConfigTokens`) supporting Zod, Valibot, and Standard Schema v1 with automatic secret redaction and Edge-safe loaders.
  - **Structured Logger Hardening (`@forge-fr/logger`, `@forge-fr/logger/edge`):** Added dot-path redaction (`user.credentials.apiKey`, wildcard paths) in `sanitizeLogContext`, created the zero-Pino Edge-safe subpath `@forge-fr/logger/edge` (`createEdgeLogger`, `createEdgeObservabilityPlugin`), and guaranteed `onError` + `onResponse` hook parity with matched `route` patterns in `attachObservabilityHooks()`.
  - **First-Class Testing Harness (`@forge-fr/testing`):** Added `createTestKernel()` and `createTestApp()` with strongly typed `[InjectionToken<T>, T]` overrides, `overrideValue()`, `Symbol.asyncDispose` (`await using`), and `TestClient` multipart, SSE (`getSse()`), and cookie-jar (`withCookies()`) helpers.
- **Milestone 3 — Security Middleware Hardening & Multipart / Streaming / Binary HTTP:**
  - **Multipart, Streaming & Binary HTTP (`@forge-fr/http`):** Fixed chunked-stream size enforcement in `readBoundedText()`, eliminated double buffer copies in `readBoundedMultipart()`, added streaming `ctx.body.multipartStream()` (`createMultipartBodyStream`), MIME/extension/magic-byte validation (`verifyMultipartMagicBytes`), filename sanitization (`sanitizeMultipartFilename`), and `ctx.formData()`, `ctx.binary()`, and RFC 6266 `ctx.download()` helpers.
  - **Unified Security Composer & Distributed Rate Limiting (`@forge-fr/security`):** Added `createSecurityMiddleware({ headers, cors, rateLimit, csrf })` enforcing safe execution order (ensuring CORS headers apply on `429`/error responses and `OPTIONS` preflight requests), sliding-window rate limiting, zero-dependency `createRedisRateLimitStore()` and `createPostgresRateLimitStore()` adapters, and hardened `extractClientIp()` (`trustRealIpHeader: false` default).
- **Milestone 4 — Database Unit of Work & Unified OpenAPI 3.1 Generation:**
  - **Unit of Work (`@forge-fr/database`, `@forge-fr/drizzle`, `@forge-fr/prisma`):** Added `UnitOfWork<TTx>` (`uow.run()`), `TransactionContext<TTx>` (`.tx`, `.repository(factory)`, `.afterCommit()`, `.afterRollback()`), `defineRepository()`, `createUnitOfWork()`, `createDrizzleUnitOfWork()`, and `createPrismaUnitOfWork()`.
  - **Unified OpenAPI 3.1 Auto-Discovery (`@forge-fr/validation`, `@forge-fr/openapi`):** Attached schemas automatically in `validatedHandler()` via `Symbol.for('forgejs.validation.schemas')`, upgraded `schemaToJsonSchema()` for Zod v4 `toJSONSchema()` + complete Zod v3/v4 & Valibot reflection (`date`, `coerce`, `discriminatedUnion`, `intersection`, `.describe()`, `.regex()`, array bounds), added `multipart/form-data` & binary media types, reusable `components.schemas`, and production guards (`enabled`, `guard`, SRI) on `registerOpenApiRoutes()`.
- **Milestone 5 — Modular CLI Code Generator (`@forge-fr/cli`):**
  - Refactored CLI templates into modular generator units under `packages/cli/src/templates/` and implemented `forge generate` / `forge g` for `module`, `resource` (full CRUD + Zod + OpenAPI + DI + tests), `schema`, `repository`, `service`, and `controller` with singular/plural inflection, pre-flight collision detection, `--dry-run`, `--dir`, `--force`, and `forge.config.json` / `package.json#forge` support.
- **Milestone 6 — Edge Runtime Hardening & Real-Time Architecture (`@forge-fr/auth`, `@forge-fr/database`, `@forge-fr/http/realtime`):**
  - Converted `@node-rs/argon2` in `@forge-fr/auth` and `postgres` in `@forge-fr/database` to lazy dynamic `import()` so Cloudflare Workers (`workerd`) and Deno bundle cleanly without bundler alias hacks, and added native Web Crypto PBKDF2-HMAC-SHA256 `createWebCryptoPasswordHasher()` to `@forge-fr/auth`.
  - Added `@forge-fr/http/realtime` (`createRealtimeHub`, `createMemoryPubSubAdapter`, `RealtimeHub`) providing room/topic pub-sub across WebSocket connections and SSE streams, pluggable cross-node pub-sub adapters, heartbeat/idle-timeout sweeps, backpressure limits (`maxBufferedAmount`), SSE `Last-Event-ID` extraction (`extractLastEventId`) with CR/LF rejection, and SSE keepalive ping comments.
- **Milestone 7 — Background Job Scheduler, Transactional Outbox & Durable Events (`@forge-fr/queue`):**
  - Added `createJobScheduler()` supporting 5- and 6-field cron expressions (`parseCronExpression`, `getNextCronTimestamp`, `@hourly`/`@daily` macros), IANA timezones (`Intl.DateTimeFormat`), fixed intervals, idempotent tick keys (`schedule:<id>:<slotTimestampMs>`), and distributed lease locks (`createMemorySchedulerLockAdapter`, `createRedisSchedulerLockAdapter`, `createPostgresSchedulerLockAdapter`).
  - Added `createTransactionalOutbox()` (`createMemoryOutboxStore`, `createPostgresOutboxStore`) staging outbox events inside the caller's database transaction (`TransactionContext` / SQL runner `tx`) with `FOR UPDATE SKIP LOCKED` relay workers forwarding committed events to `QueueAdapter` or `EventDispatcher`.
  - Added `createDurableEventBridge()` bridging `@forge-fr/core` `EventDispatcher` topics to durable `@forge-fr/queue` background jobs with retry/backoff, Dead-Letter Queue inspection (`getDeadLetterEvents`), and replay (`replayDeadLetterEvent`, `replayAllDeadLetterEvents`).
