## Where to Report Issues

- **Bug Reports:** Found unexpected runtime behavior, TypeScript typing issues, or adapter bugs? File a [Bug Report](https://github.com/forge-fr/forgejs/issues/new?template=bug_report.yml) with your runtime version (Node/Bun/Workers), package name, and minimal reproduction.
- **Feature Requests:** Have an idea for a new plugin, adapter, or API improvement? Open a [Feature Request](https://github.com/forge-fr/forgejs/issues/new?template=feature_request.yml).
- **Security Vulnerabilities:** **Never** post security issues in public issues or pull requests. Use [GitHub Private Vulnerability Reporting](https://github.com/forge-fr/forgejs/security/advisories/new) as described in [`SECURITY.md`](./SECURITY.md).
